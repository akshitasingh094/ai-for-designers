name: naming-conventions
description: Apply this naming convention whenever creating or auditing component, variant or layer names in design files.
---

When creating or auditing names in design work, apply:
- Components: Category/Component Name in Title Case
- Variant properties: Title Case nouns (State, Size, Has Icon)
- Variant values: describe state, not appearance (Disabled, not Grey BG)
- Booleans: Has… / Show…
- Layers: named by purpose (Alarm label), never "Frame 427" or "Rectangle 3"
- Tokens/styles: tier/category/role/modifier, lowercase-hyphenated
Appearance-based names break the moment the design changes; always name by purpose.

(Model-invoked: no command. Once installed, Claude applies this automatically when your task matches the description above.)
