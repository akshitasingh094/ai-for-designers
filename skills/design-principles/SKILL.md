name: design-principles
description: Apply and name these UX principles whenever giving design feedback or making a UI recommendation.
---

When giving design feedback or a UI recommendation, ground it in a named
principle and state the principle in one line. Draw from:
- Progressive disclosure — reveal on demand; don't show every action at rest
- Doherty threshold — acknowledge under 400ms; feedback before any network call
- Visibility of system status — the interface always says what just happened
- User control & freedom — reversible actions; undo before irreversible removal
- Change blindness — animate removal (~250ms) so it reads as a consequence, not a bug
- Fitts's Law — edge targets need ≥40px hit area regardless of glyph size
- Hick's Law — fewer choices, faster decisions; curate rather than dump
- Recognition over recall — show options; don't make people remember them
Never give a recommendation without naming why it holds.
