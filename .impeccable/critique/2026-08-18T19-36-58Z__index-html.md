## Priority Issues Remaining

**Status of the original 5**: #1 mobile nav — **resolved**. #2 terminal wrap — **mostly resolved** (see P3 below). #3 curl|bash trust — **partially resolved**, real but thin. #4 7-card wall — **partially resolved**, hierarchy fixed, chunking not. #5 WCAG contrast — **resolved for the 4 flagged selectors**, incomplete as a sitewide sweep.

**[P2] "Where to go next" secondary grid still exceeds the ≤4 chunking guideline**
- **Why it matters**: The hierarchy fix solves which card to click first, not how many a reader has to evaluate — 6 cards in one grid is still 50% over the minimal-choice target, most costly on mobile where they stack into a long vertical scroll.
- **Fix**: Cut the secondary grid to the 4 library/guided items (Prompts, Skills, Subagents, Path); fold Workflows + Showcase into a single inline text line instead of full cards.

**[P2] The `curl | bash` trust sentence is real but visually thin**
- **Why it matters**: This is the single highest-anxiety action on the page for a non-engineer audience, yet it gets one plain sentence while the lower-stakes "paid plan required" prerequisite above it gets a full styled callout — the visual weight is inverted relative to actual anxiety.
- **Fix**: Wrap the trust sentence in its own `.callout.tip` (or a lighter inline variant) so its visual weight matches the moment.

**[P3] Leftover `<br>` tags likely add extra vertical gap on mobile**
- **Why it matters**: `.term-body .out`/`.ok` are now `display:block` under 760px, so the trailing `<br>` immediately after each is redundant and likely renders an extra blank line stacked on top of the `12px` margin already applied.
- **Fix**: Drop the two `<br>` tags in `index.html`'s `.term-body` markup, or hide them via CSS in the same mobile media query.

**[P3] A premature exit link sits before the install section (new finding)**
- **Why it matters**: "The one idea" section ends with "Start with the foundations →" right before "First, get Claude Code running." PRODUCT.md frames `index.html` as a "two-minute on-ramp" to installing Claude Code — this link invites a literal-minded first-timer to leave for `foundations.html` before ever reaching install.
- **Fix**: Move the link to after the install section, or reword it to defer ("You'll dig into this after you're set up").

**[P3] The contrast fix is selector-scoped, not systemic**
- **Why it matters**: `--ink-3` still sits at `.nav-links .soon` and `.tag` in `base.css` — both dormant on `index.html` today, but a landmine the moment either renders here or on another page, since `--ink-3` fails AA on Paper/Card at ~2.9:1.
- **Fix**: Swap those two selectors to `--ink-2` in the same pass to close the audit rather than leave it page-specific.

## Minor Observations

- `aria-label` sits on a plain `<div class="term">` with no `role` — some screen readers may not expose the label meaningfully without `role="img"` or `role="group"`.
- Copy buttons are 100% JS-injected with no `<noscript>` fallback hint — a no-JS reader loses the affordance on the install blocks with no visible cue that manual copy is expected.
- The showcase promo card still appears before "Who this is for"/"The one idea" — asks a reader to evaluate a flashy example before they've been told what the ladder is.
- `.card-primary`'s use of Skill Violet is defensible under the Ladder-Only Rule's "generic interactive/brand moment" exception, but worth a conscious call since Foundations isn't specifically the Skill rung.
