From first prompt to first subagent, in seven days.

Twenty to forty minutes a day, each on real work you already have — not exercises. By day seven you'll have climbed the whole ladder and built the habit that makes it stick.

1Set up

Get Claude Code running & read the one ideaFoundations

You can't practise without the tool. Today is setup and orientation — nothing more.

  • Install Claude Code and sign in — the start page has the two-minute steps
  • Read Foundations end to end. It's short, and it's the spine of everything else
  • Run one throwaway prompt on a real screen you're working on, just to feel it

~30 min

2Rung 1

Put prompts to workPrompt

Today you use prompts on live work and notice which ones actually help.

  • Open the Prompt library and pick three that match what's on your plate
  • Use each on real work — a screen to spec, copy to sharpen, notes to synthesise
  • Notice which gave you something you'd have spent 20 minutes on. Those are your keepers

~30 min

3Context

Write your CLAUDE.mdSetup

Stop re-explaining your product every session. One file fixes that — and every prompt gets better because Claude now has your context.

  • Use the meta prompt “Write a CLAUDE.md for a design project” and let it interview you
  • Or start from CLAUDE.md.template in the repo and fill the brackets
  • Drop it in your project folder. Re-run yesterday's prompts and feel the difference

~25 min

4Rung 2

Install your first skill — then make oneSkill

Take the prompt you liked most on day 2 and promote it. This is the leap from typing to tooling.

  • Install one user-invoked skill from the Skills library — paste, done
  • Run it with /name on real work
  • Now make your own: the meta skill “draft a skill from a repeated prompt” converts yesterday's favourite into a SKILL.md

~35 min

5Rung 2

Install the standing rulesSkill

Model-invoked skills are habits you install once. Today you set your defaults, then watch them apply without being asked.

  • Install the model-invoked set: accessibility-standards, ux-writing-rules, design-principles
  • Ask for any UI review and notice the WCAG floor and your writing voice applied automatically
  • That's the point: quality you no longer have to remember to ask for

~25 min

6Rung 3

Delegate to your first subagentSubagent

Hand a whole task to a specialist that runs on its own.

  • Install a11y-reviewer or edge-case-hunter from Subagents
  • Point it at a real screen and let it work while you carry on in your main thread
  • Notice your working context stayed clean — the audit came back as a tidy list

~30 min

7Put it together

Run one task up the whole ladderWorkflow

Take one real feature and use all three rungs in sequence. This is what an AI-powered workflow actually looks like.

  • Prompt to explore the problem and options
  • Skill — /spec-interaction, then /handoff — to structure and package it
  • Subagent — hand the finished screen to a11y-reviewer
  • Then note the one thing you kept correcting by hand, and fold it into that skill's file

~40 min

You're there

You've run prompts, saved skills, set your standing rules, and delegated to a subagent — on your own work, not a tutorial. That's the definition of an AI-powered designer. The habit that keeps you improving is the last step of day 7: every skill gets a little better each time you fold in a correction.
