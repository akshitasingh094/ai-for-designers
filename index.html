Who this is for

You're a designer — anywhere from your first year to your fifteenth. You're good at the craft. You've maybe asked Claude to rewrite some copy or rough out a screen, but you couldn't honestly call yourself an AI-powered designer yet. You don't need theory about large language models. You need to know which tool to reach for, when, and how to make it repeatable.

That's the whole scope of this guide. Everything here is built for Claude Code specifically — the version of Claude that lives in your terminal and can read and write real files on your machine. Other tools come in a later version; this one earns its place first.

The one idea

Every technique in this guide is a rung on the same ladder. The work you repeat climbs it — from something you type, to something you save, to something that runs without you.

First, get Claude Code running

If the terminal isn't your home turf, that's expected — most designers' isn't. This takes about two minutes, and you only do it once.

One prerequisite

Claude Code needs a paid plan — Claude Pro, Max, Team, Enterprise, or an API account. The free Claude.ai tier doesn't include it. Check your plan before installing, or you'll hit a wall at first launch.

1 · Install it

Open your terminal (on a Mac that's Terminal or iTerm; search Spotlight for “terminal”). Paste one line and press return. The native installer needs no Node, no setup — it brings everything with it.

# macOS, Linux, or WSL
curl -fsSL https://claude.ai/install.sh | bash

# Windows — in PowerShell
irm https://claude.ai/install.ps1 | iex

2 · Start it and sign in

Close that terminal, open a fresh one so it picks up the new command, then run:

❯ claude

The first launch opens your browser to log in. Authorise it, and you're connected — the token is stored on your machine, so you won't do this again.

3 · Confirm it's healthy

❯ claude doctor   # checks the install, PATH, and updates
If something snags

command not found almost always means your terminal has a stale path — close it and open a new one. Anything else, the official docs have the fix: docs.claude.com/en/docs/claude-code. Install commands change; when in doubt, trust the docs over any copy here.
