Library · rung 3 — subagents

Work you hand off, entirely.

A subagent is a skill with its own room — it runs in a separate context, with its own tools and permissions, and hands back just the result. You reach for one when a job is big enough, or noisy enough, that you don't want it in your main session.

Skill or subagent?

Most work stops at a skill. Move up to a subagent only when one of these is true — otherwise you're adding machinery you don't need.

A skill is enough when…

  • The task runs in your normal back-and-forth
  • You want to see and steer each step
  • The output belongs in the current conversation

Reach for a subagent when…

  • The job can run on its own — a full audit, a synthesis pass
  • It would flood your session with output
  • You want to run several checks in parallel
  • It needs different tool access than your main work
The everyday payoff

Delegating your accessibility sweep to a subagent keeps your main thread about the design. The audit happens in its own space and comes back as a tidy list — your working context stays clean.

How to make one

A subagent is a markdown file: frontmatter that tells Claude when to use it, and a body that's its system prompt. The install on each card below writes one for you — but the easiest way to make your own is the built-in command, which walks you through it.

❯ /agents      # create, edit, and manage subagents interactively

The description line is the important part: Claude reads it to decide when to delegate automatically. Write it as a trigger — “use proactively after any UI change to…” — not just a title.

One level up: agent teams

For later — on purpose

Beyond a single subagent sit agent teams: several agents that coordinate, message each other, and carry work across sessions. It's genuinely powerful — and experimental, off by default, and easy to over-reach with before you're fluent. Get comfortable with a few good skills and one or two subagents first. When teams earn their place in your workflow, they'll be obvious; until then, they're a distraction. This guide covers them last, deliberately.
