Prompts you saved, so you never retype them.

A skill is a prompt written into a file and invoked with a /command. Each one below installs with a single copy-paste — no repo, no setup. They come in two kinds, and the difference matters.

❯ User-invoked

You type /name to run them. The verbs of your workflow — spec this, audit that, hand this off. You decide when.

Model-invoked

No command. Claude reaches for them automatically when your task matches their description. Standing rules — your accessibility floor, your writing voice — always on.

How to think about it

User-invoked skills are tools you pick up. Model-invoked skills are habits you install once and forget — they quietly shape every relevant answer without you asking. A strong setup has a handful of each.

Installing a skill

Every card has a copy-paste install. It writes the skill straight into your Claude Code skills folder — you don't need this repo cloned. To confirm what you've got:

❯ ls ~/.claude/skills     # everything you've installed, across all projects
These are yours to change

Once installed, a skill is just a markdown file you own. Used one five times and kept correcting the same thing by hand? Open its SKILL.md and fold the fix in. The version you end up with beats the one you were handed.
