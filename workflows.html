Recipes · the ladder at work

Whole jobs, start to finish.

A single prompt is rarely the whole task. These are recipes — real design jobs broken into ordered steps, each one reaching for the right rung: a prompt to explore, a skill to structure, a subagent to delegate. Every step links to the exact library item it uses.

How to read these

The coloured chip on each step tells you which rung it's on. You'll see the ladder climb inside a single job — explore with prompts, structure with skills, hand off the heavy parts to subagents. Follow the links to grab each piece.

New to the ladder these are built on? Start with Foundations. Want to build the habit day by day? Follow the 7-day path.
